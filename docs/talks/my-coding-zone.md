### Abstract

*"That's not how we do it here."* — *"How was I supposed to know?"*

New team members often learn a project's conventions only through code review findings, which is frustrating for everyone. AI makes this harder: code is produced faster than ever, but who checks whether it actually fits the project?

In this session we make team knowledge **executable**. We build a **CodeRule engine** that automatically verifies architecture, APIs and coding standards using tests, Roslyn and analyzers. Rules are written and tested live, and AI generates new rules including tests, while humans define the quality bar.

The result: a **self-defending codebase** that guides both new team members and AI while they develop.
